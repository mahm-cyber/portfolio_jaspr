# Implementation Plan: Figma Portfolio Design

## 1. Design Analysis & Theme Setup
*   **Colors**: Based on the Figma data and typical "Product Designer" templates:
    *   **Background**: Dark Grey/Black (`#171717` or similar).
    *   **Primary/Accent**: Vibrant Orange (`#FD853A`).
    *   **Surface**: Darker Grey (`#262626`) for cards/buttons.
    *   **Text**: White (`#FFFFFF`) and Light Grey (`#9CA3AF`).
*   **Typography**: "Plus Jakarta Sans" (already configured).
*   **Layout**:
    *   **Header**: Floating pill-shaped navigation bar.
    *   **Hero Section**: Asymmetric grid layout.
        *   Left: "Hello" badge, Headline ("I’m Jenny..."), Description.
        *   Center/Right: Large Profile Image (masked in circle/blob).
        *   Floating Elements: "10 Years Experience" card, "Testimonial" card.

## 2. Asset Management
*   **Download**: Fetch the following assets from Figma:
    *   Profile Image (`profile.png`)
    *   Icons: Quote, Star, Arrow, Social Media icons (Facebook, YouTube, WhatsApp, Instagram).
*   **Location**: Store in `web/images/` and `web/icons/`.

## 3. Component Implementation
*   **`lib/constants/theme.dart`**: Update `AppColors` to match the Dark+Orange theme exactly.
*   **`lib/components/header.dart`**: Refactor to match the pill-shape design with "Active" (Orange) and "Inactive" (Transparent/Outlined) states.
*   **`lib/pages/home.dart`**:
    *   Implement the **Hero Section** using `CSS Grid` for precise positioning of the text, image, and floating cards.
    *   Add the "Experience" and "Testimonial" floating cards using absolute positioning or grid overlaps.
*   **`lib/components/buttons.dart`**: Update `PrimaryButton` to be the "Hire Me" (Orange) and "Portfolio" (Dark/Outlined) styles.

## 4. Semantic HTML Structure
*   `header`: Navigation.
*   `main`:
    *   `section.hero`: Intro and Profile.
    *   `section.stats`: Experience counters.
*   `footer`: Social links and copyright.

## 5. Verification
*   Verify responsiveness (Flexbox wrapping).
*   Check hover effects (scale/color change).
