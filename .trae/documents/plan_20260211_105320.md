# Implementation Plan: Jaspr Portfolio with Flutter Integration

## 1. Design System Extraction & Setup
*   **Color Palette:**
    *   **Primary:** `#292D32` (Dark Grey/Black from text icons) & `#OP018E` (Deep Purple/Blue from Text) - *To be sampled exactly from hex codes.*
    *   **Accent:** Orange (`#RXTHNE` equivalent) for active states.
    *   **Neutral:** White (`#FFFFFF`) and Light Gray (`#F5F5F5`).
*   **Typography:**
    *   **Headings:** Bold, Sans-serif (e.g., 'Plus Jakarta Sans' or similar modern font).
    *   **Body:** Readable sans-serif.
*   **Components:**
    *   `CapsuleButton`: Rounded (60px radius) for Nav items.
    *   `HeroCard`: Composition of text + vector illustrations.
    *   `StatsBadge`: "10 Years Experience" floating card.

## 2. Technical Architecture (Clean Architecture)
The project will be structured to separate concerns, ensuring scalability and testability.

```
lib/
├── core/                   # Shared utilities, constants, error handling
├── domain/                 # Business logic (Entities, UseCases, Repository Interfaces)
│   ├── entities/           # Project, Testimonial, Skill
│   └── repositories/       # IProjectRepository, IContactRepository
├── infrastructure/         # Data layer (Implementations, Data Sources)
│   ├── datasources/        # Static JSON files or API clients
│   └── repositories/       # ProjectRepositoryImpl
├── presentation/           # UI Layer (Jaspr)
│   ├── components/         # Reusable widgets (NavBar, ProjectCard)
│   ├── pages/              # Route pages (Home, About, Projects)
│   ├── theme/              # AppTheme, Colors, TextStyles
│   └── state/              # Riverpod Providers
└── main.dart               # App Entry point
```

## 3. Tech Stack & Libraries
*   **Framework:** `Jaspr` (Dart Web Framework).
*   **Language:** Dart 3.x.
*   **State Management:** `Riverpod` (riverpod_annotation).
*   **Styling:** CSS-in-Dart (Jaspr's native styling) or Tailwind.
*   **Routing:** `jaspr_router`.
*   **Icons:** `lucide_icons` or SVG exports.

## 4. Feature Implementation Steps
1.  **Project Initialization:** Create Jaspr project, set up folder structure.
2.  **Theme Implementation:** Define `AppColors`, `AppTextStyles` constants.
3.  **Component Library:** Build atomic components (`Button`, `NavPill`, `SectionTitle`).
4.  **Layout Construction:** Implement the Main Layout (NavBar + Footer).
5.  **Page Development:**
    *   **Home:** Hero Section, Stats, Testimonial snippet.
    *   **About/Resume:** Timeline view of experience.
    *   **Projects:** Grid view with hover effects.
6.  **Flutter Integration:**
    *   Use `jaspr_flutter_embed` (if applicable) to embed a mini Flutter app demo in the "Projects" section to demonstrate Flutter skills live.

## 5. Asset & Performance Optimization
*   **Images:** Convert all PNG/JPG to WebP. Lazy load off-screen images.
*   **Vectors:** Inline critical SVGs, load others as assets.
*   **Code Splitting:** Use Jaspr's `@deferred` loading for heavy routes (e.g., Projects page).

## 6. Testing & Quality Assurance
*   **Unit Tests:** Verify business logic (e.g., filtering projects by tag).
*   **Widget Tests:** Verify component rendering using `jaspr_test`.
*   **Linter:** `very_good_analysis` or `flutter_lints`.

## 7. Deployment Pipeline
*   **CI/CD:** GitHub Actions.
*   **Build Command:** `dart run jaspr build --release`.
*   **Target:** GitHub Pages (static hosting).

## Milestone Estimates
*   **Phase 1 (Setup & Core UI):** 2 Days - Project structure, Theme, NavBar.
*   **Phase 2 (Content Pages):** 3 Days - Home, About, Services.
*   **Phase 3 (Projects & Integration):** 2 Days - Project Grid, Flutter Embeds.
*   **Phase 4 (Polish & Deploy):** 1 Day - Mobile responsiveness, SEO meta tags, Deployment.
